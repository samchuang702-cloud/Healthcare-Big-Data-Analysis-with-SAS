# 醫療大數據分析 — SAS 健保資料分析

## 專案簡介

本專案為「醫療大數據分析」課程作品，使用 SAS 分析台灣全民健康保險研究資料，從門診、住院與承保資料中建立病人層級指標，並分析外傷性腦損傷（Traumatic Brain Injury, TBI）的醫療利用情形與高門診量醫院。

## 想解決的問題

- 如何從門診與住院資料辨識 TBI 病人？
- TBI 病人的門診、住院次數與醫療點數分布為何？
- 如何整併跨月份、跨資料表的健保資料？
- 哪些醫院的門診量最高？

## 技術方法

1. 整併 12 個月份的門診資料。
2. 依主要診斷碼篩選 TBI 門診與住院紀錄。
3. 使用病人 ID 彙整就醫次數與醫療點數。
4. 串接承保資料取得性別欄位，並處理遺漏值。
5. 建立總醫療點數並產出描述性統計。
6. 計算各醫院門診量，排序並列出前 10 名。

## 分析內容

| 分析主題 | 內容 |
|---|---|
| TBI 病人辨識 | 依主要診斷碼篩選門診與住院紀錄 |
| 醫療利用 | 計算門診／住院次數與醫療點數 |
| 資料整併 | 串接 ENROL、OPDTE 與 IPDTE 資料 |
| 描述性統計 | 最小值、最大值、平均數與標準差 |
| 醫院排名 | 計算門診量並列出前 10 名醫院 |

因健保研究資料受使用規範限制，本 repository 不公開原始資料、病人層級資料或分析輸出。

## 使用技術

SAS、DATA Step、PROC SQL、PROC SORT、PROC TABULATE、PROC PRINT。

## 專案亮點

- 完成跨月份與跨資料表的健保資料整併流程。
- 建立病人層級的醫療利用與醫療點數指標。
- 實作條件篩選、分組彙總、遺漏值處理與排名。
- 展現 SAS 程式設計、醫療資料處理與統計分析能力。

## 執行方式

1. 使用 SAS 9.4 或相容環境開啟 `Medical_Big_Data_Analysis.sas`。
2. 修改程式最上方的 ENROL、IPDTE、OPDTE 與輸出資料夾路徑。
3. 準備具合法使用權限的健保研究資料後執行程式。
